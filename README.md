# 🦉 رياضيات الثالث الابتدائي مع بومة

تطبيق تعليمي تفاعلي (أندرويد للموبايل والتابلت) مبنيّ على **كتاب الرياضيات** و**كتاب التمرينات** للصف الثالث الابتدائي – جمهورية العراق، وزارة التربية (الطبعة الثامنة ١٤٤٧هـ / ٢٠٢٥م).

- **٩ فصول، ٥٧ درساً**: الأعداد حتى ٩٩٩٩، الجمع، الطرح، تمثيل البيانات، القياس، الهندسة، الكسور، الضرب، القسمة.
- لكل درس: **أتعلّم** (شرح مبسّط خطوة بخطوة مع رسوم وصوت) ← **أتأكّد وأحلّ** (تمارين الكتاب) ← **كراس التمارين** ← **تدرّب أكثر** (تمارين جديدة بلا نهاية) ← **تحدّي الدقيقة** ⏱️.
- **اختبار** في نهاية كل فصل.
- ١٥٦١ تمريناً من الكتابين، و٢٢ نوعاً من التمارين التفاعلية: الجمع والطرح العمودي مع الحمل والاستلاف خطوة بخطوة، الضرب العمودي، المقارنة، الترتيب، القيمة المكانية، التقريب، الأنماط، التمثيل بالأعمدة، الساعة، الكسور، المساحة والحجم، وغيرها.
- واجهة عربية بالكامل من اليمين إلى اليسار، والأرقام عربية (٠١٢٣٤٥٦٧٨٩) كما في الكتاب.
- نجوم وأوسمة، وأصوات، وقراءة الشرح بصوت عربي.
- يعمل **بدون إنترنت**، ويحفظ التقدّم على الجهاز.

## 📲 كيف أحصل على ملف APK؟ (بدون أي برامج على الحاسوب)

1. أنشئ مستودعاً جديداً على GitHub واجعله **Private** (خاص).
2. **أولاً** أنشئ ملف البناء: **Add file ← Create new file**، واكتب في خانة الاسم بالضبط:
   `.github/workflows/build-apk.yml`
   ثم انسخ محتوى الملف نفسه من المجلد (افتحه بأي محرّر نصوص) والصقه، واضغط **Commit changes**.
   > لماذا؟ لأن مجلد `.github` مخفي في الويندوز/الماك وقد لا يُرفع بالسحب والإفلات.
3. ثم **Add file ← Upload files** واسحب باقي الملفات والمجلدات: `www` و`assets` و`keystore` و`tools` و`package.json` و`package-lock.json` و`capacitor.config.json` و`README.md` و`.gitignore`.
   > ⚠️ لا ترفع مجلد `node_modules` إن وُجد.
4. اذهب إلى تبويب **Actions**؛ سيبدأ البناء تلقائياً (٥–١٠ دقائق). إن لم يبدأ، اختر «بناء تطبيق أندرويد (APK)» ثم **Run workflow**.
5. عند ظهور ✅ اذهب إلى **Releases** (يمين صفحة المستودع) وحمّل ملف `riyadiyat3-vN.apk`. (المستودع خاص، لذا حمّله وأنت مسجّل الدخول، ثم انقله إلى الجهاز.)
6. على الموبايل/التابلت افتح الملف وثبّته (فعّل «السماح بالتثبيت من هذا المصدر» عند السؤال).

كل مرة تعدّل فيها شيئاً وترفعه، يُبنى إصدار جديد تلقائياً. التطبيق موقّع دائماً بالمفتاح نفسه (`keystore/debug.keystore`)، لذا يمكن **تحديثه فوق القديم دون حذف التقدّم**.

## 🔊 الصوت
القراءة بالصوت تستخدم محرّك تحويل النص إلى كلام في الجهاز. إذا لم تسمع صوتاً: الإعدادات ← النظام ← اللغة ← تحويل النص إلى كلام ← اختر **Google** وثبّت اللغة **العربية**.

## 🛠️ للمطوّرين
```bash
npm install
npm test                 # فحص سلامة بيانات الدروس
npx cap add android
npm run assets           # توليد الأيقونات وشاشة البداية
npx cap sync android
npx cap open android     # فتح المشروع في Android Studio
```
- المحتوى في `www/data/ch1.js … ch9.js` (الكتاب) و`wb1.js … wb6.js` (كتاب التمرينات).
- يمكن تجربة التطبيق في المتصفح بفتح `www/index.html`.

## 📁 بنية المشروع
```
www/
  index.html
  css/style.css          تصميم «دفتر المربّعات»
  js/core.js             أدوات مشتركة، الحفظ، الأصوات، القراءة الصوتية
  js/visuals.js          الرسوم (مكعبات العدّ، الساعة، الكسور، الأعمدة، المجسّمات…)
  js/widgets.js          أنواع التمارين التفاعلية
  js/gens.js             مولّدات «تدرّب أكثر»
  js/app.js              الشاشات والتنقّل
  data/                  الدروس والتمارين
assets/                  أيقونة التطبيق وشاشة البداية
.github/workflows/       بناء APK تلقائياً
```

> للاستخدام العائلي والتعليمي. محتوى التمارين مأخوذ من كتب وزارة التربية العراقية، والشروح مكتوبة بأسلوب مبسّط.
